The preceding benchmarks often provide \texttt{assert} goals. To test
goal-independent generation, we remove all such assertions and compare with
\autospec~\cite{autospec} (C/ACSL) and \specgen~\cite{SpecGen} (Java/JML).

\subsection{Experimental Setup}
We construct \textbf{\toolname-400} from \textbf{FormalBench}~\cite{le2025can}
(250 Java programs), \textbf{SpecGenBench} (59 Java programs), and native-C
\textbf{SV-COMP} (91). FormalBench originally contains OpenJML-verified Java
programs with sequential, branching, and loop-based structures. We translate
the Java programs to C while preserving
control flow and data dependencies \rev{(\appref{app:benchmark-translation})},
remove all \texttt{assert} statements, and use the Frama-C/WP protocol of
Section~\ref{sec:experiments} (Z3, Typed memory model).

All LLM methods use \texttt{gpt-4o}, \texttt{gpt-5-mini},
\texttt{gpt-5.4-mini}, and \texttt{gpt-5} at temperature 0.7 under Pass@1.
Using one model family limits cross-family training and capability differences;
the models in Section~\ref{sec:experiments} were fixed by its baselines.

We compare full \toolname\ (up to 10 refinement iterations), its \emph{w/o
refine} and \emph{Pure LLM} (also without symbolic execution) ablations, and
one-shot \autospec\ in C/ACSL. We run \specgen\ on the original Java programs
in Java/JML as a cross-ecosystem reference. The ablations isolate symbolic
guidance and refinement; only \autospec\ shares our verifier setting. Each
run has a 1800-second outer timeout.

On all 400 programs, without the per-program compute cap of
Section~\ref{sec:experiments}, we measure validity, strength, cost, and failures.
\emph{Valid} means that the verifier discharges every obligation induced by the
generated specification within the configured budget. The questions are:
\begin{itemize}
    \item \textbf{RQ5:} How often does \toolname\ produce a
    \emph{Valid} specification?
    \item \textbf{RQ6:} How strong are \toolname's specifications
    versus the baselines?
    \item \textbf{RQ7:} What does \toolname\ cost in time, tokens, and
    API calls?
    \item \textbf{RQ8:} What are \toolname's dominant failure modes?
\end{itemize}
