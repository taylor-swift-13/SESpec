\section{Proof of the Strongest-Postcondition Guarantee}
\label{app:sp-proof}

\yfp{This appendix proves Proposition~\ref{thm:sp-sound-complete}.}

\yfp{
\begin{proof}
Denote $\textit{SP}(\mathcal{F},P,p_{\textit{start}},p_{\textit{end}})$ by $\Phi$. Let $s_{\mathrm{entry}}$ denote the function-entry state and $s$ an endpoint valuation. We first establish that $\Phi$ characterizes the reachable values on each path's tracked locations, then prove maximality within the scope of the definition.

(Soundness): Consider a concrete execution represented by the incoming symbolic state under $P$. By (A1), it is well-defined and reaches $p_{\textit{end}}$ along a feasible path $\pi$. By (A2), symbolic execution enumerates this path, $PC_\pi$ holds, and the symbolic store gives the concrete endpoint value of every tracked location. Thus, the reached valuation satisfies $\ell^{p_{\textit{end}}}=\sigma_{p_{\textit{end}},\pi}(\ell)$ for every $\ell\in\operatorname{dom}(\sigma_{p_{\textit{end}},\pi})$. It therefore satisfies $PC_\pi\land\rho(\sigma_{p_{\textit{end}},\pi})$ and hence $\Phi$.

(Completeness): Let $(s_{\mathrm{entry}},s)$ satisfy $\Phi$. Some disjunct $PC_\pi\land\rho(\sigma_{p_{\textit{end}},\pi})$ holds under this pair. Since $PC_\pi$ includes $P$, the function-entry values satisfy the incoming constraints. Incoming-state exactness in (A2) supplies a corresponding segment-start state. By (A1) and the exact path conditions and symbolic stores in (A2), concrete execution follows $\pi$ to an endpoint valuation $t$ that agrees with $s$ at every location tracked on that path. Thus all tracked values specified by the disjunct are realized by a concrete execution.

(Maximality): Let $\Psi$ be any postcondition within this scope such that $\{P\}\,\mathcal{F}\,\{\Psi\}$ holds. For any $(s_{\mathrm{entry}},s)$ satisfying $\Phi$, completeness supplies a concrete endpoint valuation $t$ on a feasible path $\pi$. The Hoare triple gives $\Psi(s_{\mathrm{entry}},t)$. On $\pi$, the truth of $\Psi$ depends only on the function-entry values and the tracked endpoint values. Since $s$ and $t$ agree on these tracked values and share the same function-entry state, $\Psi(s_{\mathrm{entry}},s)$ also holds. Therefore $\Phi\Rightarrow\Psi$. Under the exact path conditions, $\Phi$ itself depends only on the function-entry values and the corresponding path's tracked endpoint values, so it lies within the same scope. Together with soundness, this establishes the strongest-postcondition claim.
\end{proof}
}
