# RQ7 cost data

`reanalysis/summary.json` and `reanalysis/per_case.csv` are generated by
`tools/recompute_rq7_cost.py` for all 400 gpt-5.4-mini programs and five
workflows. The CSV records the source of every case-level cost. Original raw
outputs remain under `../rq5_validity/runs/`.

The original AutoSpec time, API-call count, and validity labels are used for
all 400 cases. Forty-four summaries absent from the paper-data copy were
recovered from the AutoSpec source archive. In 39 cases, exactly one original
per-call token record is missing. We estimated that call's usage from a
same-model rerun step in `reanalysis/reruns/autospec/` and retained the other
original per-call records. Failed and interrupted rerun attempts are
kept in numbered `_incomplete_` directories. Three SESpec costs missing from
the original paper-data copy come from a later same-model archive; this makes
the RQ7 cost-cohort validity count differ from the original RQ5 run by three.

The archived 646-case three-model exploratory summary is retained as
`reanalysis/legacy_three_model_cohort.json` for provenance. The paper's Fig. 5
uses only the complete 400-case gpt-5.4-mini reanalysis.
